# Playbook: Surgical Refactoring and Modernization Flow

This playbook defines the systematic execution steps for modernizing legacy codebase components, updating consumer-focused interfaces to high-density, AI-friendly enterprise blocks.

---

## Phase 1: Gap Mapping and Structural Disruption Analysis
1. **Identify Loose Design Traces**: Scan the target file for sparse B2C consumer tokens (such as giant fonts, excessive padding, or bloated layouts).
2. **Pin Legacy Dependencies**: Map elements that violate the system core (such as naked array index iteration keys, loose floating sub-components, or standard browser input alerts).

## Phase 2: High-Density and Semantic Inversion Execution
1. **Compact Rescaling**: Inject Chakra UI v3 compact variables (`size="sm"`) and monospace numerical tags (`fontFamily="mono"`) across data cells.
2. **Apply Compound Patterns**: Bundle loose sub-components together into structured namespaces using `Object.assign`, eliminating file footprint sprawl.
3. **Resilience Engineering**: Embed active network blockers (`loading={isSubmitting}`) onto every data mutation path and replace blank array voids with robust, descriptive `<EmptyState>` widgets.

## Phase 3: Regression Testing and Clean Completion
1. **Surgical Scope Focus**: Ensure adjacent configuration paths, helper utils, and unrelated styles remain completely untouched during the upgrade window.
2. **Checklist Validation Gate**: Run the completely upgraded file tree through the global `ux-checklist.md` and `responsive-checklist.md` criteria to seal the modernization task.
