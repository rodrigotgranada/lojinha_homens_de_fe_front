# Glossary: Enterprise UX (Visual Density)

## Definition
An interface design paradigm optimized for professional data velocity, structural scannability, and interface resilience, completely rejecting sparse B2C consumer whitespace layouts.

## Architectural Rules
* **Compact Scaled Design**: Mandatory use of compact design scaling tokens (`size="sm"` or `size="xs"`).
* **Asynchronous Safety Guards**: Interface operations must lock immediately via loading overrides during processing to eliminate race conditions.
* **Data Typography Standard**: Enforced usage of monospace formatting (`fontFamily="mono"`) for all numeric tables, hashes, and timestamps.
